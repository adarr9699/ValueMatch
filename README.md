💖 Value Match

💚Introduction:

Value Match is a dating app that is designed to connect people based their core values, interests,and personal traits other than appearance alone 
Value Match is was made to promotes meaningful connections, improves relationships compatibility, and help people fine partnesers who share the same personal values.

💚 MVP Features:

Users Authentication:
 - Sign up & long in using Firebase Authorization
 - Secure email & password system
 - Add name, age, bio
 - Select core values
 - Choose interest and personality traits
 - Save profile to Firestore

Matching System 
 - Compare users profile based on matching logic
 - Generate compatibility scores
 - Display fit- match

Navigation 
  - Login
  - Signup
  - Home dashboard
  - Profile screen
  - Match screen
  - Messaging screen

💚 Technologies:

Frontend
 - Kotlin
 - Jetpack Compose
 - Material 3
 - Navigation Compose
   
Backend
 - Firebase Authentication
 - Firebase Firestore
 - Firebase Storage
 - Firebase Messaging

Build 
 - Gradle
 - Android Studio
