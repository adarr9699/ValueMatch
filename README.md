💖 Value Match

💚Introduction:

Value Match is a dating app that is designed to connect people based their core values, interests,and personal traits other than appearance alone 
Value Match is was made to promotes meaningful connections, improves relationships compatibility, and help people fine a partner who share the same personal values.

💚 MVP Features:

Users Authentication:
 - Sign up & Longin using Firebase Authorization
 - Secure Email & Password System
 - Add Name, Age, Bio
 - Select Core Values
 - Choose interest and personality traits
 - Save profile to Firestore

Matching System 
 - Compare Users Profile Based on Matching logic
 - Generate Compatibility scores
 - Display Match

Navigation 
  - Login
  - Signup
  - Home Dashboard
  - Profile Screen
  - Match Screen
  - Messaging Screen

💚 Technologies:

 Frontend

 - Jetpack Compose

Backend
